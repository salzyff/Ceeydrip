# Ceeydrip Jewelry

A responsive React storefront mockup for Ceeydrip Jewelry, built with Vite. It uses the brand's black-and-gold visual identity, jewellery and watch categories, placeholder photography, and direct Instagram and WhatsApp links.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production files are written to `dist/`.
